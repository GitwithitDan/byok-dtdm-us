Before you paste a key

  • The form builder, validator and download need no key at all and send nothing anywhere. Your draft is kept in this browser only, so a refresh does not lose it.
  • A key is used only by the optional "Describe it" box. It is stored in this browser's localStorage only if you tick "Remember on this device".
  • Requests go directly from your browser to the provider you pick (Anthropic, OpenAI, or Google). No DTDM server sees your key, your inputs, or your results.
  • The whole tool is one readable HTML file. Use View source above and check the request code yourself.
  • Use a dedicated key, set a spend limit on it in your provider's console, and delete it when you're done. Don't have a key yet? Find my API key.

Host it on your own site

  1. Copy full code above, or Download .html.
  2. Save it as rcal-builder.html, or paste it into a file ending in .html.
  3. Upload it to any static host, or double-click it to run locally. It has its own key field and stores a remembered key on your site, separate from this one.

The .rcal format is open and maintained by EventStrand. This builder follows spec v0.2; check the generated file against the current spec at eventstrand.com before publishing.
