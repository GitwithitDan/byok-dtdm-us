About your API key

  • It's stored in your browser's localStorage only if you tick "Remember on this device". Otherwise it's never saved.
  • Requests go directly from your browser to your provider (Anthropic, OpenAI, or Google). DTDM never sees your key or your results.
  • Each tool is one readable HTML file with no dependencies. Open a tool page and use View source to check the request code before you run it.
  • Use a dedicated key and set a spend limit on it in your provider's console. Delete the key when you're done.

Copied or downloaded tools don't update themselves. Check the version tag on each tool's page for newer releases.
