Before you paste a key

  • The key is stored in this browser's localStorage only if you tick "Remember on this device". Leave it unticked and nothing is saved.
  • Requests go directly from your browser to the provider you pick (Anthropic, OpenAI, or Google). No DTDM server sees your key, your inputs, or your results.
  • The whole tool is one readable HTML file. Use View source above and check the request code yourself.
  • Use a dedicated key, set a spend limit on it in your provider's console, and delete it when you're done. This tool runs live web searches, which cost more per run than a plain chat reply.

Host it on your own site

  1. Copy full code above, or Download .html.
  2. Save it as cost-of-living.html, or paste it into a file ending in .html.
  3. Upload it to any static host, or double-click it to run locally. It has its own key field and stores a remembered key on your site, separate from this one.

Figures are estimates built from web sources at the time you run it. Verify anything that drives a real decision.
