What is .rcal?

.rcal is an open, plain-JSON file format for describing the repeating rhythm of real-world life: "jazz every Friday at 9", "book club the second Thursday", "market every Saturday May to September, closed Christmas." Anyone can read, write, or build tools around it with no licence or fee. This tool follows spec v0.2, maintained by EventStrand.

It is not iCal. An .ics file records commitments you are doing. A .rcal file encodes possibility: what could be happening, on a repeating pattern, published by a venue, person, or community. It is not a calendar sync protocol.

  • Keep ids stable. Apps match updates by id. Changing one makes subscribers see a different event.
  • Times are 24-hour and read in the strand's timezone. An end time earlier than the start runs past midnight.
  • Rules add up. Several recurrence rules on one event merge, so "weekdays plus extended Saturday" is two simple rules.
  • Unknown fields are kept. Parsers should ignore what they don't recognise, so files stay compatible as the spec grows.
  • Going live is a promise. If live is on, the file must stay at its source_url. People who scanned your QR code point at that exact address.
