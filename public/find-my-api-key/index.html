Find or create your API key.

An API key is a long password that lets a tool use an AI model on your account. You make one in the provider's developer dashboard, then paste it into any tool here.

Claude OpenRouter Keep it safe

A ChatGPT or Claude subscription is not an API key

Paying for ChatGPT Plus, or using Claude in the app, does not give you API access. The API is a separate product in a separate dashboard, billed per use. You create the key there, and you only pay for what the tools you run actually use.

The tools on this site work with two providers only: Anthropic (Claude) and OpenRouter. OpenRouter is how you reach OpenAI, Gemini, Mistral, Meta and many other models: one OpenRouter key, then type the model you want into the tool. Some providers, such as OpenAI, do not allow direct calls from a browser page, so a key from them would not work in these tools.

Claude

Anthropic · Claude Console
Works with every tool here
  1. Sign in to the Claude Console at platform.claude.com, or create an account.
  2. Open the API keys page at platform.claude.com/settings/keys.
  3. Click Create key. Give it a name, choose an expiration, and set Linked account to yourself. A workspace is optional.
  4. Copy the key straight away. The Console shows the full key once. If you lose it, create a new one.
  5. Add credit or a payment method in the Console's billing section before your first request, or calls will fail.

If "Create key" is greyed outYour role in the organization may not allow it. Ask an admin.

Source: Claude Platform Docs, "Get your Claude API key". Billing step from a third-party guide: Apideck.

OpenRouter

OpenRouter · one key, many models
Works with every tool here
  1. Sign in at openrouter.ai, or create an account.
  2. Add credits on the credits page at openrouter.ai/settings/credits. Credits are prepaid, so you cannot spend more than you add.
  3. Open the keys page at openrouter.ai/settings/keys and create a new key.
  4. Give it a name. If the form offers a credit limit or an expiration, set both. A limit caps what this one key can spend.
  5. Copy the key straight away. It is shown once. If you lose it, create a new one.
  6. In a tool, pick OpenRouter and type the model you want, written as provider/model. Each model's ID is shown on its page at openrouter.ai.
Key starts withsk-or-
CostEach model has its own price, shown on its OpenRouter page. A fee applies when you buy credits.

Source: OpenRouter API docs, "Create keys" (key limit, reset and expiration options) and OpenRouter spend-controls guide (credits and the credits page). Button labels were not confirmed in the dashboard, so match the closest name if yours differs.

Keep your key safe

  • Make a dedicated key for these tools. If anything goes wrong you can delete just that one.
  • Set a spend limit or usage alert in the provider's billing settings before you run anything.
  • Never post a key in a chat, email, screenshot, or public code. Anyone who has it can spend your money.
  • Leaked or unsure? Delete the key in the dashboard right away and create a new one.
  • Only tick "Remember on this device" on a computer you own. Leave it unticked on shared or public machines.

Tools on this site send your key only to the provider you pick (Anthropic or OpenRouter), straight from your browser. DTDM never sees it.

Questions

I pay for ChatGPT or Claude. Why do I still need a key?

Chat subscriptions and API access are separate products with separate billing. The key comes from the developer dashboard linked above, and you pay per use there.

I closed the window and can't see my key.

Keys are shown once when created. Make a new one and delete the old one.

The tool says my key was rejected (401).

Check that you pasted the whole key with no spaces, and that the provider dropdown in the tool matches where the key came from. A Claude key will not work under OpenRouter, and the reverse.

The tool says I hit a limit (429).

Your account is out of credit, or you are over a rate or spend limit. Check billing and limits in the provider's dashboard, wait a minute, and try again.

How do I use OpenAI, Gemini or other models?

Pick OpenRouter in the tool, paste your OpenRouter key, and type the model ID (provider/model) from that model's page on openrouter.ai. OpenRouter bills you for it; you do not need a separate key from the model maker.
