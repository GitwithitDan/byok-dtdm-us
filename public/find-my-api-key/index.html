Find or create your API key.

An API key is a long password that lets a tool use an AI model on your account. You make one in the provider's developer dashboard, then paste it into any tool here.

Claude ChatGPT / OpenAI Gemini Grok Mistral DeepSeek Keep it safe

A ChatGPT or Claude subscription is not an API key

Paying for ChatGPT Plus, or using Claude in the app, does not give you API access. The API is a separate product in a separate dashboard, billed per use. You create the key there, and you only pay for what the tools you run actually use.

The tools on this site currently call Claude, OpenAI and Gemini. Grok, Mistral and DeepSeek are listed below for when you want a key for other apps or for tools added later.

Claude

Anthropic · Claude Console
Works with every tool here
  1. Sign in to the Claude Console at platform.claude.com, or create an account.
  2. Open the API keys page at platform.claude.com/settings/keys.
  3. Click Create key. Give it a name, choose an expiration, and set Linked account to yourself. A workspace is optional.
  4. Copy the key straight away. The Console shows the full key once. If you lose it, create a new one.
  5. Add credit or a payment method in the Console's billing section before your first request, or calls will fail.
Key starts withsk-ant-
If "Create key" is greyed outYour role in the organization may not allow it. Ask an admin.

Source: Claude Platform Docs, "Get your Claude API key". Billing step from a third-party guide: Apideck.

ChatGPT / OpenAI

OpenAI · API platform
Works with every tool here
  1. Sign in at platform.openai.com. This is the developer platform, not chatgpt.com. Use the same email if you like, but it is a separate dashboard.
  2. Open API keys from the left sidebar, or go to platform.openai.com/api-keys. You need an organization set up first.
  3. Click Create new secret key. Add a name, choose the permission level (full or restricted), and pick a project if asked.
  4. Copy the key immediately and store it somewhere safe. Treat a key you can no longer see as lost and make a new one.
  5. Open Billing in the dashboard and add credits or a payment method so requests go through.
Key starts withsk-
TipChoose a restricted key if the dialog offers it, and limit it to what the tool needs.

Source: Maxim guide to getting an OpenAI API key. Menu names can shift, so match the closest label if yours differs.

Gemini

Google · AI Studio
Works with every tool here
  1. Go to aistudio.google.com/app/apikey and sign in with your Google account.
  2. On your first visit, accept the terms and confirm your region. The Gemini API is not available in every country.
  3. Click Get API key in the left sidebar, then Create API key.
  4. Choose Create key in new project (the simple default), or pick an existing Google Cloud project if you already use one.
  5. Copy the key and store it somewhere safe.
Key starts withAIza
CostA free tier exists with rate limits. For higher limits, turn on billing for the linked Google Cloud project; the same key keeps working.

Optional hardening: in the linked Google Cloud project's Credentials page you can restrict the key to the Generative Language API and set quotas.

Source: Apideck guide to the Gemini API key. Free-tier limits change often; check your AI Studio dashboard for the current numbers.

Grok

xAI · xAI Console
Not used by the tools here yet
  1. Sign up or sign in at console.x.ai. Email, Google and X sign-in are supported.
  2. Finish the short onboarding and accept the API terms. Read any data-sharing offer carefully before you accept it.
  3. Click API Keys in the left sidebar, then Create API Key.
  4. Name the key and choose its team, allowed endpoints and allowed models.
  5. Copy the secret immediately. It is shown once.
  6. Add a payment method under Billing and set a monthly spending cap.
Key starts withxai-
CreditsNew accounts may get promotional credits. Check the console for the current offer.

Source: Apideck guide to the xAI API key.

Mistral

Mistral AI · Studio console
Not used by the tools here yet
  1. Open the Studio console at console.mistral.ai and sign in.
  2. Click API Keys in the left sidebar.
  3. Click Create new key. Enter a name, set an expiration date, and choose the connector access scope.
  4. Click Create new key again to confirm.
  5. Copy the key immediately. The full key is shown once.
CostAPI access is on by default in Free mode with no credit card. Usage and rate limits still apply.

Source: Mistral docs, "Activate Studio and generate an API key".

DeepSeek

DeepSeek · API platform
Not used by the tools here yet
  1. Go to platform.deepseek.com and sign up with an email address or phone number.
  2. Open Top up and add credits. Keys will not work until the balance is funded.
  3. Click API keys in the left sidebar, then Create new API key.
  4. Name the key and confirm.
  5. Copy the key immediately. It is shown once.

Source: Puter guide to the DeepSeek API key.

Keep your key safe

  • Make a dedicated key for these tools. If anything goes wrong you can delete just that one.
  • Set a spend limit or usage alert in the provider's billing settings before you run anything.
  • Never post a key in a chat, email, screenshot, or public code. Anyone who has it can spend your money.
  • Leaked or unsure? Delete the key in the dashboard right away and create a new one.
  • Only tick "Remember on this device" on a computer you own. Leave it unticked on shared or public machines.

Tools on this site send your key only to the provider you pick, straight from your browser. DTDM never sees it.

Questions

I pay for ChatGPT or Claude. Why do I still need a key?

Chat subscriptions and API access are separate products with separate billing. The key comes from the developer dashboard linked above, and you pay per use there.

I closed the window and can't see my key.

Keys are shown once when created. Make a new one and delete the old one.

The tool says my key was rejected (401).

Check that you pasted the whole key with no spaces, and that the provider dropdown in the tool matches where the key came from. A Claude key will not work under OpenAI, and the reverse.

The tool says I hit a limit (429).

Your account is out of credit, or you are over a rate or spend limit. Check billing and limits in the provider's dashboard, wait a minute, and try again.

Which provider is cheapest to try?

Gemini has a free tier with rate limits, so it is the lowest-friction way to try a tool. Prices for the paid providers change often; check each provider's pricing page.

Dashboard layouts change. Steps above were checked on Oct 27, 2026. If a button is named slightly differently, pick the closest match, or check the provider's own docs linked in each section.
